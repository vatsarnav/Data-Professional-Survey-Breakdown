# Data Professional Survey Breakdown

Data Professional Survey Breakdown is an interactive **Power BI data analytics project** that explores survey responses from professionals working in the data field.

The project analyzes factors such as **job roles, salaries, programming language preferences, geographic location, work-life balance, job satisfaction,** and the **difficulty of entering the data profession**. The results are presented through an interactive Power BI dashboard designed to make workforce trends easier to explore and understand.

## Overview

The data profession includes a wide range of roles, technical skills, compensation levels, and career experiences. This project brings survey responses together into an interactive dashboard to explore these differences and identify patterns across data professionals.

The dashboard provides visual analysis of **salary by job title, programming language preferences, respondent locations, work-life balance, salary-related satisfaction,** and **career-entry difficulty**.

## Key Features

* Analyzes survey responses from data professionals

## Dashboard

The Power BI report is presented as an interactive dashboard containing multiple visualizations.

### Average Salary by Job Title

Compares average salary across different data-related job titles and provides a view of compensation differences between roles.

### Favorite Programming Language

Visualizes programming language preferences among survey respondents and allows comparisons across different professional roles.

### Country of Survey Takers

Shows the geographic distribution of survey respondents and provides insight into where the surveyed data professionals are located.

### Happiness with Work-Life Balance

Measures respondents' reported satisfaction with their work-life balance.

### Happiness Index in Relation to Salary

Explores the relationship between salary levels and respondents' reported happiness.

### Difficulty to Break into Data

Shows how respondents perceive the difficulty of starting a career in the data field.

### Summary Metrics

Provides high-level metrics from the survey through KPI-style cards, including respondent and age-related information.

## Data Analysis

The dashboard was designed to answer questions such as:

* **How does average salary vary across data-related job titles?**
* **Which programming languages are most commonly preferred?**
* **Where are data professionals located?**
* **How satisfied are respondents with their work-life balance?**
* **How does salary relate to reported happiness?**
* **How difficult do respondents find it to enter the data profession?**

## Project Workflow

### 1. Data Preparation

The survey data was prepared for analysis and structured so that it could be explored effectively within Power BI.

### 2. Data Analysis

The survey responses were analyzed across different professional and demographic categories, including job title, salary, programming language, location, and satisfaction measures.

### 3. Dashboard Development

The analyzed data was transformed into an interactive Power BI dashboard using a combination of charts, summary cards, and visual elements.

### 4. Data Visualization

Different visualization types were selected to communicate salary comparisons, programming preferences, geographic distribution, satisfaction levels, and career-related responses.

### 5. Insight Exploration

The completed dashboard allows users to interact with the survey data and explore patterns across different aspects of the data profession.

## Results

The completed dashboard provides an interactive view of **career, salary, technical skill, and workplace satisfaction trends** among survey respondents.

The visualizations make it easier to compare professional roles, explore salary differences, understand programming language preferences, and examine respondents' experiences within the data field.

## Getting Started

### Prerequisites

Before opening the project, make sure you have:

* **Microsoft Power BI Desktop** installed
* The project `.pbix` file
* Access to any required source data if the report needs to be refreshed

### Open the Project

Download or clone the repository:

```bash
git clone <repository-url>
cd <repository-name>
```

Open the Power BI project:

```text
Data Professional Survey Breakdown.pbix
```

The dashboard can then be explored using the available visualizations and interactive filters.
